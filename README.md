# Website — Montador de Móveis

Landing page desenvolvida para um profissional montador de móveis, com foco em apresentar seus serviços e facilitar o contato com potenciais clientes.

## Sobre o projeto

Projeto de desenvolvimento web criado para transformar as necessidades de um cliente em uma página comercial personalizada, com identidade visual e navegação intuitiva.

## Tecnologias

* HTML5
* CSS3
